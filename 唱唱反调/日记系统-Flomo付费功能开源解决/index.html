    📔 日记系统：Flomo 付费功能开源解决¶

    约 2273 个字 9 行代码 预计阅读时间 11 分钟

    作者：NeuraSailor × ClaudeCode

    一年多来我一直用 Flomo 记日记。记着记着发现一件事不对劲："记日记"这件本该完全属于你自己的事，正被包装成按月付费的会员功能。 想看"相关笔记"？PRO。想要"AI 洞察"？PRO。想要一个懂你的 AI 伙伴、一份记忆档案？MAX。

    这篇文章记录我怎么把 Flomo 的付费 AI 功能全部用开源方案平替掉，同时拿回数据的完全所有权。核心就两件事：数据本地化（flomo-bridge 同步到本地文件夹）+ 能力开源化（用我的几个 Claude Code skill 复刻 PRO/MAX 功能）。

    一、先谈立场：日记值得记，数据不该被绑架¶

    日记有必要¶

    记日记是少数"投入极低、复利极高"的习惯。每天花三分钟记下当天做了什么、在想什么，一个月后回看，你会惊讶于自己当时的状态和现在的差距；一年后回看，那是任何 AI 都生成不出来的、只属于你的时间线。很多想法当时觉得理所当然，记下来之后才知道它是怎么一步一步长成现在这个样子的。

    我甚至觉得，日记是人对抗遗忘、建立自我认知最便宜的工具。它值得被认真对待——包括认真对待"它存在哪里"。

    Flomo 通过"绑架"你的日记信息赚钱¶

    Flomo 的商业模式值得掰开看：免费让你记，但你的每条日记都锁死在它的服务器和客户端里。想导出？想要 AI 帮你回顾、帮你把碎片串成主线？请开通 PRO / MAX 会员。

    这非常像微信——你的聊天记录、你的朋友圈，全部封闭在它的私有围墙里，你只有使用权，没有所有权。日记是你最私密的思考产物，让它被一个 app 绑架、还要按月付费才能"赎回"自己的数据，这件事我越想越不对。

    想清楚这一点之后，我决定把"记录"和"能力"拆开：记录继续用 Flomo（输入体验确实好），但数据必须落在自己手里；AI 能力则全部用开源工具自己搭。

    二、解决思路：数据本地化，能力开源化¶

    一句话概括整个方案：

    Flomo（仅作为记录 / 输入入口）
      │  flomo-bridge 自动同步
      ▼
Obsidian 仓库（本质就是一个本地文件夹）
      │  我的 4 个 Claude Code skills
      ▼
复刻出 PRO / MAX 的全部 AI 功能

    好处很直白：

    • 数据主权：日记是一个个 .md 文件，存在你自己硬盘上，能读、能搜、能用 git 管、永远不会因为某个 app 改版/倒闭而消失。
    • 能力免费：PRO/MAX 的 AI 功能用本地 skill 复刻，不再为会员费买单（AI 本身走你已经有的 Claude Code 配置）。
    • 可迁移：哪天不想用 Flomo 了，文件夹还在，什么都不会丢。

    三、第一步：用 flomo-bridge 把 Flomo 笔记同步到本地¶

    🌐 github.com/giraffe-tree/flomo-bridge

    flomo-bridge 是一个开源的 Obsidian 插件，能把你的 Flomo 笔记同步到 Obsidian 仓库，还带双向链接。配置很简单：

    1. Obsidian 里装好 flomo-bridge 插件
    2. 填上你的 Flomo token（插件会自动验证）
    3. 设置同步目录（比如 flomo/），设个同步间隔

    同步之后你会发现一件震撼的事：你几年攒下的日记，本质就是一堆纯文本 .md 文件。 每篇都带完整的元信息：

    ---
slug: MjE4NzM5Mzcx
created_at: "2026-01-29 22:50:16"
updated_at: "2026-01-30 09:40:47"
tags: ["review"]
source: "android"
---

日记内容

    Obsidian 仓库"本质就是文件夹"——这句话不是比喻。这意味着你的日记从此可以被 grep、被脚本批量处理、被 git 版本管理、被任何工具读取。数据主权在这一步就回来了。

    四、第二步：用我的几个 skill 复刻 VIP/MAX 的 AI 功能¶

    Flomo的ai功能是有想法的，应该覆盖了日记反思回顾联想的所有场景（虽然没什么技术含量🤣）。

    具体理念参考help.flomoapp.com/ai/agent.html

    笔记同步到本地之后，真正值钱的部分来了：把 Flomo 锁在付费墙后面的 AI 功能，用 Claude Code 的项目级 skill 全部复刻。

    我写了 4 个 skill，一一对应 Flomo 的付费功能：

    Flomo 付费功能 付费门槛 我的开源替代 skill
    flomo Agent（懂你的 AI 对话伙伴） MAX flomo-agent
    相关笔记（语义相关推荐） PRO flomo-related
    AI 洞察（多视角深度分析） PRO flomo-insight
    AI 记忆档案（画像 + 记忆文档 + 碎片） MAX flomo-memory

    它们都放在 vault 的 .claude/skills/ 目录里，Claude Code 会自动发现。下面是每个的功能。

    flomo-agent —— 复刻 MAX 的 Agent¶

    Flomo 的 Agent 卖点是"读过你所有笔记、像熟悉的朋友一样对话"。我的 flomo-agent skill 做到了同样的事：它先读取全部笔记建立索引，然后每次回答都引用具体笔记、标注日期来源，把你的碎片串成连贯的自我认知。

    • 和笔记对话：问"我是谁"，它从你的记录里拼出画像；问"最近反复出现但没察觉的是什么"，它提炼暗线。
    • 内置技能：昨日回声（翻一条旧笔记，找出与另一处对不上的地方，留一个真问题）、每日新知（从你写过的点延伸新知识）、行为洞察（照出你反复出现的默认动作）、幸福灵药（状态不好时给一句不鸡汤的重新框定）。
    • 记忆系统四步：存底 → 挑拣 → 归拢 → 成像，把散落对话沉淀成对你的整体认识。
    • "聊完存进 flomo"写回：确认后把讨论按你的标签和语气写成新笔记（写进独立的 ai-writeback/ 目录，不污染同步源）。

    flomo-related —— 复刻 PRO 的相关笔记¶

    Flomo 的相关笔记靠"语义模糊匹配"跨标签找相关条目，这是 PRO 功能。flomo-related skill 用 LLM 做语义判断，不看关键词重合，能把不同标签下主题一致的笔记串联起来：

    • 复习启发：写一条新卡片后看相关笔记，等于一次基于间隔重复的主动复习。
    • 写作素材：给一个选题，它把相关笔记和原文片段全捞出来。
    • 连续探索：点开某条推荐，以它为锚继续推荐，能无限多轮；"隐藏同标签"、"移除标签再看"都能切换视角。

    flomo-insight —— 复刻 PRO 的 AI 洞察¶

    Flomo 的 AI 洞察用多个视角分析你的笔记，识别核心主题、揭示思维盲点、提出深刻问题。flomo-insight skill 复刻了这套，还带9 个视角：每日肯定、行动指南、意义雷达、心底之问、亚里士多德、塞涅卡、价值澄清、逆向思考，外加自定义视角。

    • 每条洞察都标注来源笔记（引用标记 + 文件路径 + 原文片段），能溯源回现场。
    • 结尾给"更好的问题"清单——只给问题不给答案。它坚持 Flomo 那句设计理念：AI 不替你思考，而是激发你更深入地思考。

    flomo-memory —— 复刻 MAX 的 AI 记忆档案¶

    Flomo 的记忆档案把笔记提炼成三份结构化记忆：用户画像（你是谁）、记忆文档（你在想什么）、记忆碎片（逐条结构化记忆）。flomo-memory skill 完整复刻：

    • 生成过程四阶段：读取笔记 → 提取记忆 → 整合档案 → 完成。
    • 同样有 30 条笔记的门槛（不足会明确拒绝并告诉你还差几条），同样手动触发、不会自动更新。
    • 产物写入 记忆档案/ 文件夹的三个 .md 文件——可以直接复制到其他 AI 工具的系统提示词里，也可以接 MCP 让 AI 每次对话都能读到。

    五、效果对比：花钱 vs 开源¶

    维度 Flomo PRO/MAX 会员 我的开源方案
    数据位置 锁在 Flomo 服务器 本地.md 文件夹，随时可导
    AI 对话伙伴（Agent） MAX flomo-agent skill
    相关笔记 PRO flomo-related skill
    AI 洞察 PRO flomo-insight skill
    记忆档案 MAX flomo-memory skill
    每月费用 会员费 无（AI 走已有 API 配置）
    可定制 不能 每个 skill 都是你的，随便改

    代价当然也有：要自己装插件、配 skill、偶尔处理小问题——但这就是把能力拿回自己手里的代价，我觉得很值。

    六、写在最后¶

    回到开头那句话：日记值得记，数据不该被绑架。

    工具的意义是让记录这件事变得顺畅，而不是把记录本身变成你的负债。现在我每天照常记 Flomo，但心里很清楚——它只是一个输入法，我的思想存在我自己硬盘上，我的 AI 引擎跑在自己搭的 skill 里。

    如果你也在为"数据该归谁"纠结，这套方案（flomo-bridge 同步 + 4 个 skill 复刻付费功能）是一个可以照抄的起点。所有东西都是开源的，你的日记终于只属于你。

    这里是「唱唱反调」——不拘一格，独立思考。数据是你的，AI 也是你的。
