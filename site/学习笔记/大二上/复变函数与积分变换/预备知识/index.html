    引入复数并介绍辐角、辐角主值、复数的三角/指数表示、几何意义。

    辅角 \(Argz = \theta\); 辅角主值 \(argz = \theta_0\)（\(-\pi < \theta \leq \pi\)）

    1. 在复数范围内，一个数的 n 次方根有且只有 n 个不同的解。
    2. 棣莫弗公式：\((\cos \theta + i\sin\theta)^n = \cos(n\theta) + i\sin(n\theta)\)（证明：指数函数）
    3. 推广：证明 n 倍角公式
    4. \((\cos \theta - i\sin\theta)^n = \cos(n\theta) - i\sin(n\theta)\)
