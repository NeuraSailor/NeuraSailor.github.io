| **《兵经》**     | 春秋战国           | 兵法要领，军事纲领                                               | 较早兵法著作，兵书雏形         |

| **《司马法》**    | 春秋战国           | “权处于战”战争本质；“天下虽安，忘战必危“”战备思想；“顺天、阜财、泽众、利地、右兵”确定战争胜负的基本观点 | 最早提出国防战备系统理论        |
| **《尉缭子》**    | 春秋战国           | 军制建设、将帅与纪律                                              | 最早系统阐述军事制度的专著       |
| **《六韬》**     | 春秋战国           | 六韬分类战略                                                  | 最早全面论述战略战术的兵书       |
| **《孙膑兵法》**   | 战国             | 进攻思想、阵势战术体系                                             | 战国代表军事理论            |
| **《三略》**     | 汉朝             | 治国与治军结合                                                 | 首部系统论述治国和军事实务结合的兵书  |
| **《淮南子》**    | 西汉（约公元前139年）   | 哲学与军事战略思想                                               | 汉初战略与治军智慧体现         |
| **《战略》**     | 魏晋南北朝          | 实战兵略，用兵策略                                               | 早期战略理论兵书            |
| **《太白阴经》**   | 唐朝（7-8世纪）      | 阴阳、天象与阵法探讨                                              | 阴阳天文兵法代表著作          |
| **《李靖兵法》**   | 唐朝（7世纪初）       | 奇正变阵，军队管理                                               | 唐代实战兵法著作            |
| **《李卫公问对》**  | 唐朝             | 奇正相变，战例结合                                               | 结合战例探讨兵法先河          |
| **《武经总要》**   | 宋朝             | 军队组织、阵法、武器、军事地理                                         | 第一部官修军事类书           |
| **《武经七书》**   | 宋朝             | 汇集七大经典兵书                                                | 第一部军事丛书选集           |
| **《百将传》**    | 宋朝（张预）         | 历代名将传记                                                  | 第一部系统军事人物传记集        |
| **《历代兵制》**   | 宋朝（陈傅良）        | 兵制沿革                                                    | 第一部军制史专著            |
| **《守城录》**    | 宋朝（陈规）         | 城防体系和守城战术                                               | 第一部城邑守防专著           |
| **《纪效新书》**   | 明朝（1560-1584年） | 结合实战经验的兵书及练兵教材                                          | 明代实用军事著作            |
| **《练兵实纪》**   | 明朝（1571年）      | 注重军队训练实用细节                                              | 继《纪效新书》后完善练兵指导      |
| **《武备志》**    | 明朝（茅元仪）        | 综合军事理论及实务                                               | 体量最大综合军事百科全书        |
| **《筹海图编》**   | 明朝（郑若曾）        | 海防战略与抗倭                                                 | 第一部海防专著             |
| **《火龙神器阵法》** | 明朝（焦玉）         | 火器制造与使用                                                 | 首部火器系统技术兵书          |
| **《读史方舆纪要》** | 清朝（顾祖禹）        | 军事地理与国防战略                                               | 第一部军事地理专著           |

|朝代阶段|主要兵种|武器装备及军制特点|
|---|---|---|
|夏商西周（公元前21世纪-前8世纪）|夏：步兵为主；商周：战车为主，步兵辅助|兵器由原始的木石兵器逐步向青铜兵器过渡。商周时期以青铜兵器为主，战车是主战兵种。兵农合一制度，民军制萌芽。军事教育重视礼、射、御。|
|春秋战国（公元前8世纪-前3世纪）|步兵为主，辅以骑兵、弩兵和舟师|铁器广泛使用，青铜兵器衰退，远射武器（弩）得到改进和广泛应用。车兵地位下降，多兵种协同作战体系形成。战争频繁，军制和兵书体系丰富发展。|
|秦至五代（公元前221年-960年）|骑兵逐渐为主战兵种，步兵辅助，车兵地位下降|铁质兵器成为主流，冷兵器战争显著，集权中央军制建立。兵权与军事指挥系统趋向完善，边疆防务重视骑兵。军事思想结合实践形成古代军事学术体系。|
|宋元明清（960年-1840年）|宋元多步兵为主，明清步兵、骑兵、火器兵结合|冷热兵器并用，火药武器（火铳、火炮等）在宋朝后期兴起，明清火器大规模使用。兵役制度改革，宋朝募兵制，元朝军户制，明朝卫所制，清八旗、绿营制度成型。军事著作丰富并官修。|
