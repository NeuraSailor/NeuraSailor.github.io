# 考试
#考试
本次考试闭卷。考试范围：人工智能基础概念、深度学习、卷积神经网络、循环神经网络、自然语言处理、大模型等。考试题型如下（总分超过100分，计100分）。

一、判断题（20分，20题，每题1分）

二、单选题（30分，15题，每题2分）

三、多选题（20分，10题，每题2分）多选少选都不给分

四、计算题（15分，3题，每题5分）

五、问答题（15分，3题，每题5分）

六、附加题（10分，1题，计入总分）

问答题一定要写

注意课件上附的代码
