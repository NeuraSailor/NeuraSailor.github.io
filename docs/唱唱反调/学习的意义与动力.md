# 学习的意义与动力

## 总体陈述

**开场**
- 我本想说：应试教育不对，再帮大家找到学习的意义——写着写着我发现，找不到
- 教育资源的座位就那么多，总得有个规则决定给谁，这个规则就是高考。这一点，我不瞒你们
- 但今天要说的，不只是这个
- 要说的是：**在不得不穿过这扇门的同时，怎么别把自己弄丢**

**预告**
- 下面三个贴士，每个都能带走。记住一个，就算没白听

### 贴士一：分清内卷和努力

**现象**
- 现在谁学得狠一点，就被叫"卷王"——好像努力是件丢人的事
- 但内卷和努力，根本是两回事

**内卷是什么**
- 内卷（involution）：投入越来越多，产出却不再增长
- 一群人抢同一块蛋糕：每个人都更拼命伸手，蛋糕没变大，只是大家都更累了
- 一句话：**高消耗、零增长，才叫内卷**

**内卷从哪来（结构性，不是任何人的错）**
- 马克思《资本论》第一卷·第二十三章：
  > "工人阶级中就业部分的过度劳动，扩大了它的后备军的队伍，而后者通过竞争加在就业工人身上的增大的压力，又反过来迫使就业工人不得不从事过度劳动和听从资本的摆布。"
- 位置有限、替补无限，竞争就必然退化成"比谁更能熬"
- 这是结构，不是谁的错——**内卷的锅，丢给社会环境**

**所以：你们的努力，不是内卷**
- 努力 = 你在长大：你学到的长在你身上，谁都拿不走
- 卷王们其实是在努力。他们不该被嘲笑，你们的努力也一样
- **高中，努力是光荣的，不该心虚**

### 贴士二：保留一件考试考不到的东西

**背景**
- 马克思《资本论》第一卷·第二十三章：
  > "过剩的工人人口是积累或资本主义基础上的财富发展的必然产物……过剩的工人人口形成一支可供支配的产业后备军。"
- 列宁《列宁全集》第三卷：
  > 失业工人后备军"是资本主义制度的一种'经济上的需要'……因为没有这种后备军，资本主义就不可能发展到目前的高度，甚至也不可能存在。"
- 只要资本还在积累，就永远有人"随时可替换"——这是个事实，先记住它

**所以：你凭什么不被替换？**
- 凭别人复制不走的东西：你的爱好、你的想法、你的脾气、你特别在意的某件事
- 它们可能上不了卷子，但它们是你不在"谁都能替代"名单里的底气
- **有自己特点的人，不可替代；不可替代的人，卷不动**

**但保留它们，不只是为了不被卷掉**
- 更重要的是：**你本身，就该存在**
- 这两年的考试会不断暗示你：你的价值等于你的分数——这是错的
- 你的价值，从你出生那天起就在那里，不需要任何一场考试来证明
- **别让应试教育，把你磨成一张统一的脸**

### 贴士三：提前想清楚"你想成为谁"

**现状**
- 大多数人第一次认真想"未来要做什么"：报志愿那几天
- 在完全不知道自己适合什么的情况下，三天决定四年甚至更久——中国学生最被动的一刻。强调主动性。

**怎么做**
- 你们可以提前想起来
- 不需要现在就有一个确定的答案，只要开始问自己：
  - 我未来想成为什么样的人？
  - 我喜欢做什么？我擅长什么？
  - 我想过什么样的生活？
- 前面有一个"未来"在等着，这两年的每一分努力都会不一样
- 你不是在为一场考试努力，你是在为你想成为的那个人铺路

【待填：你自己的例子——你是怎么开始想"未来要做什么"的？选了什么方向？中间走过什么弯路？】

### 结尾

- 记住一句话：**高考决定你去哪，不决定你是谁**
