# 🧰 常用工具七件套：我的一天被它们串起来

> **作者**：NeuraSailor × ClaudeCode

电脑上的软件装了删、删了装，最后每天真的会打开的，其实就七件。把它们列出来才发现：这七件不是孤立的 App，而是把"**想到一件事 → 做完一件事**"的整条路串了起来。

这篇文章不推荐任何新工具，只记录**我现在每天真正在用的**，和我最常碰它们的地方。

---

## 1. Claude Code：干活的引擎

终端里的 AI 编程助手。写代码、改文件、批量整理笔记、部署这个博客——全在这里完成。它的定位是"**动手**"：你说需求，它直接把文件改了、命令跑了，不跟你废话。

## 2. Claude Desktop：学习的副驾驶

和 Claude Code 一个偏"做"、一个偏"学"。课件 PDF 拖进去让它用大白话讲一遍，复杂概念直接生成可视化 HTML，看到不懂的选中文字就问。它是"**懂**"的地方。

## 3. VSCode：写代码的落笔处

Claude Code 在终端里改代码，但真正盯着代码、跑调试、看 diff 的地方是 VSCode。两者是同一个项目的两个窗口——**一个动手，一个检查**。对我来说它更像 Claude Code 的"审稿人"。

## 4. 滴答清单：所有想法的落点

接进了手机上的 Claude，走在路上想到一件事，说一句 AI 就记成带截止时间的任务。它是"**记**"的地方——所有"要做什么"都先落到这里，防止脑子一热就忘。

## 5. Obsidian：知识的仓库

所有笔记的第二个大脑。双向链接、本地 Markdown、随手就能发布成这个博客。学到的东西、踩过的坑、实验记录，都往这里扔。它是"**沉淀**"的地方。

## 6. Edge：所有信息的入口

查资料、看论文、逛 GitHub、上 Claude 网页版……浏览器永远是打开频率最高的那个。它是"**查**"的地方，也是唯一一个我几乎不会主动关掉的软件。

## 7. UU远程：不在电脑前时的兜底

最大的使用场景：人不在主力机旁边，但活儿还在。远程连回宿舍那台电脑，跑长任务、取文件、接着用 Claude Code——**图书馆的笔记本瞬间变成主力机的远程显示器**。

---

## 🔗 七件套怎么串成一天

```
想法/任务          查资料          沉淀           学习           动手做               兜底
滴答清单    →     Edge     →    Obsidian   →   Claude Desktop →  VSCode+Claude Code →  UU远程
(说一句就记下)  (搜/读/逛)    (记成笔记)     (弄懂概念)      (把想法变成现实)      (不在也能干)
```

一个典型的流程：在 Edge 里看到一篇有意思的文章 → 丢进 Obsidian 记一笔 → 相关任务记进滴答清单 → 遇到不懂的概念打开 Claude Desktop 问 → 要落地成代码就在 VSCode 里让 Claude Code 写 → 人不在电脑前就用 UU远程 回来接着干。

---

## 💭 写在最后

工具不在于多，在于**每天真的会打开**。这七件套里没有一样是"为装而装"的——它们各自管住一段路，合起来恰好覆盖了从"想到"到"做完"的全过程。

*这里是「唱唱反调」——不拘一格，独立思考。你的常用工具是什么？*
