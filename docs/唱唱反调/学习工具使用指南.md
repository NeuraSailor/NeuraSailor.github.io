# 🛠️ 我的学习工具链：让 AI 替你打工

有的同学期末才到处求往年卷，有的同学开学第一周就拿到了全部资料；有的人对着 PDF 一行行抄笔记，有的人一键导出 Markdown 直接复习。

这篇文章聊聊我电脑上那些真正在用的工具——不是"推荐清单"，而是每天打开电脑就会碰的东西。它们共同组成了我的学习工作流，而且**全部免费可用**。

---

## 1. Claude Code：一切的基础

> 🌐 [anthropic.com/claude-code](https://www.anthropic.com/claude-code)

**[Claude Code](https://www.anthropic.com/claude-code)** 是我电脑上最重要的工具，没有之一。它是个**命令行里的 AI 编程助手**，由 Anthropic 开发，但远不止写代码。

简单说，它能读取你整个项目、理解上下文、然后直接修改文件、运行命令。它不是聊天框里问你"要不要这样做"，而是**直接动手做**。就像雇了一个随时随地待命的程序员，你说需求，它干活。

我用它来：

- **批量处理文件**：几十个 Markdown 笔记的格式统一、链接修复，一句命令跑完。
- **搭建工具**：下面提到的很多工具（PPT-Master、MAICUI 等）本身就是用 Claude Code 配置的。
- **自动化杂活**：重命名、整理目录、转换格式……凡是重复性工作，丢给它就完了。
- **调试和部署**：这个博客站点本身，从 CSS 样式到 GitHub Pages 部署，全在 Claude Code 里完成。

**怎么获取**：官网下载安装，终端里敲 `claude` 即可启动。通过[cc-switch](https://github.com/farion1231/cc-switch)配置deepseek api。

## 2. Claude Desktop（Cowork 模式）：日常学习的副驾驶

> 🌐 [anthropic.com/claude](https://www.anthropic.com/claude)
**Claude Desktop**（桌面客户端）有一个专门为日常工作学习设计的模式——**Cowork（协作模式）**。

和 Claude Code 不同，Claude Code 擅长"做东西"（写代码、改文件），而 Claude Desktop 的 Cowork 模式擅长"教东西"和"管东西"。你可以把它理解为一个**住在你电脑桌面上的全能家教**：

- **课程讲解**：把课件 PDF 直接拖进对话框，让它用费曼学习法讲一遍——用最简单的话把概念说清楚。听不懂就追问，它可以换三种方式解释同一个概念，比很多网课都好使。
- - **生成可视化 HTML**：遇到复杂概念时，直接让它生成交互式 HTML 页面——电路图、公式推导动画、概念关系图，浏览器打开就能交互，比静态笔记直观得多。
- **实时互动问答**：听课或者看书遇到不懂的，选中文字就能问。它会结合上下文解释，不像搜索引擎那样给你一堆无关链接。而且它记得你之前聊过什么，不会每次都要重新交代背景。
- **资源整合**：它可以读取你电脑上的文件——课件、笔记、往年试卷——把它们关联起来。比如问"这道题考的是哪个知识点？"，它能从你的课件和笔记里找到对应内容，甚至告诉你在哪一页。


**怎么获取**：官网下载 Claude Desktop 客户端（Windows/Mac 都有），同样通过[cc-switch](https://github.com/farion1231/cc-switch)配置deepseek api。

核心体验就一个词：**随时可问**。不用组织语言、不用挑关键词——就像身边有个学霸，不懂就问。

## 3. MinerU：PDF 解析神器

> 🌐 [github.com/opendatalab/MinerU](https://github.com/opendatalab/MinerU) 

大学里最多的就是 PDF——课件、论文、实验指导、往年试卷……大部分是扫描件，想复制一段文字都难。

**[MinerU](https://github.com/opendatalab/MinerU)** 是我用过最强的 PDF 解析工具，完全开源免费：

- **扫描件 OCR**：手写笔记、老旧扫描教材都能识别，数学公式也能转成 Markdown，不是截图，是真的可编辑文本。
- **保留结构**：标题、段落、表格、公式，输出的 Markdown 结构清晰，不是那种乱成一团的纯文本。
- **速度极快**：几十页的课件几秒出结果（flash 模式），质量不够还能升到 VLM 模式用视觉模型精细解析。
- **多格式支持**：PDF、图片（JPG/PNG）、Office 文档（Word/PPT）都能转。

**怎么获取**：GitHub 开源，`pip install mineru` 即可安装。也可以直接用 Web 版（浏览器上传即解析，零配置）。

实际场景：老师发的课件 PDF → MinerU 解析 → 导入 Obsidian → Claude Code 帮忙整理重点 → 生成复习笔记。原本要花半天的事，十分钟搞定。

## 4. PPT-Master：做 PPT 不再痛苦

> 🌐 [github.com/hugohe3/ppt-master](https://github.com/hugohe3/ppt-master) 

大学里做 PPT 的频率比想象中高得多——课程汇报、大作业展示、竞赛答辩、社团竞选……而且每次都从空白页开始。

**[PPT-Master](https://github.com/hugohe3/ppt-master)** 是一个开源的 AI PPT 生成工具，直接把文档或主题变成真正的 PowerPoint 文件：

- 给它一个主题或大纲（甚至直接给一篇笔记）
- 自动生成结构化的 PPT 内容——标题页、目录、内容页、总结页
- 支持**原生形状、图表、动画**，不只是文字堆砌
- 支持**自定义模板**，统一配色和字体
- 导出 `.pptx`，再用 PowerPoint 微调即可

**怎么获取**：GitHub 开源，clone 下来装依赖即可运行。也可以用 Claude Code 的 skill 模式直接调用（我就是这么干的）。

不用从头搭框架、不用纠结排版、不用对着空白幻灯片发呆。把精力花在**讲什么**上，而不是**怎么做**上。

## 5. OPENMAIC：虚拟课堂

> 🌐 [github.com/THU-MAIC/OpenMAIC](https://github.com/THU-MAIC/OpenMAIC)

**[OPENMAIC](https://github.com/THU-MAIC/OpenMAIC)**（Open Multi-Agent Interactive Classroom）是一个开源的**多智能体虚拟课堂**。它的名字就说清楚了：开放、多智能体、互动式课堂。

核心思路是模拟一个真实的课堂环境，但老师是 AI：

- **多角色教学**：不是单一 AI 在讲，而是多个 AI 智能体分别扮演讲师、助教、同学，模拟真实的课堂讨论。你可以随时提问，不同角色会从不同角度回答。
- **按章节组织**：导入一门课的内容后，自动拆成结构化的学习路径——每个知识点有讲解、例题、常见疑问、拓展阅读。
- **互动式问答**：不是单向灌输，你可以追问、质疑、要求换个方式解释。就像上课时举手提问一样自然。
- **一键启动**：不需要复杂配置，一个命令就能在浏览器里打开你的虚拟课堂。

**怎么获取**：GitHub 完全开源，clone 后配置 API Key 即可。支持接入各种 LLM（Claude、GPT 等），也支持本地模型。

它解决了一个很实在的问题：**课后复习时，不知道该看什么、看到什么程度算掌握**。OPENMAIC 把一门课拆成了可量化的学习路径，跟着走就行。

## 6. MAIC-UI：知识可视化

> 🌐 [github.com/THU-MAIC/MAIC-UI](https://github.com/THU-MAIC/MAIC-UI) — 清华大学 MAIC 实验室开源

抽象的概念难以理解，但是可视化的图形就容易记住。尤其是电磁学这种概念多、关系杂的课，画一张图比看十页笔记有用。

**[MAIC-UI](https://github.com/THU-MAIC/MAIC-UI)**（Making Interactive Courseware with Generative UI）是清华大学人机交互实验室开源的一个**交互式知识可视化工具**。核心思路是用 AI 自动把知识变成可交互的可视化页面：

- 把知识点之间的关联画成**思维导图**和**关系图**
- 用**流程图**梳理推导过程（比如电路分析中的等效变换步骤）
- 用**时间线**整理历史事件和公式发展脉络
- 用**对比表格**整理易混淆概念（比如电磁学中的动生电动势 vs 感生电动势）
- 所有可视化内容都是**交互式**的，点击节点可以展开细节，而不是静态图片

**怎么获取**：GitHub 开源，支持 Web 版和本地部署。可以直接在浏览器里用，也可以部署到自己的服务器上。

## 7. ZJU-Learning-Assistant：资料一站式下载

> 🌐 [github.com/PeiPei233/zju-learning-assistant](https://github.com/PeiPei233/zju-learning-assistant) — 开源

学在浙大、智云课堂这些软件做的特别差，下载课件、试卷、答案都要点开一个个链接，并且经常因为糟糕的校园网无法打开。

**[ZJU-Learning-Assistant](https://github.com/PeiPei233/zju-learning-assistant)** 是专为浙大学生开发的一款桌面工具，做了几件事：

- **多源聚合**：聚合学在浙大、智云课堂等多个平台的课程资料（课件、试卷、答案、实验报告）
- **一键下载**：选择课程即可下载全部资料到本地，按课程和学期自动归档
- **链接检测**：自动检查资料链接有效性，过期提醒更新
- **桌面客户端**：基于 Tauri 框架，Windows/Mac/Linux 都有原生客户端，不是网页套壳

**怎么获取**：GitHub Releases 页面下载安装包，登录学在浙大账号即可使用。

## 🔗 工具之间的关系

这些工具不是孤立的，它们串成了一条流水线：

```
资料获取              内容处理              知识吸收              输出成果
ZJU-Assistant   →   MinerU            →  Claude Desktop    →  PPT-Master
(下载课件/试卷)       (PDF→Markdown)       (讲解+每日计划)       (做汇报PPT)
                                          ↓
                                    Claude Code（底层引擎：自动化、整合、部署）
                                          ↓
                                    OPENMAIC（结构化复习+虚拟课堂）
                                    MAIC-UI（交互式知识可视化）
```

每一个环节都有 AI 替你干脏活，你只需要做最重要的那件事：**思考**。

## 💭 写在最后

有人说用 AI 工具是"偷懒"。我觉得不是——**把重复劳动交给机器，把思考留给自己，这不叫偷懒，这叫效率。**

上学期期末，我用这套工具链三天复习完了集成电路基础。不是因为我聪明，而是因为我不用花时间找资料、抄笔记、整理格式。我的精力全花在了真正重要的地方：理解差分放大电路为什么能抑制共模信号、推导负反馈的闭环增益公式。

工具的意义就在这里——**让你专注于只有你才能做的事**。
