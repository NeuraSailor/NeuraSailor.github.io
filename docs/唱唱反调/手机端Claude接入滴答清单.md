# 📅 手机端 Claude 接入滴答清单：让 AI 替你管日程

> **作者**：NeuraSailor × ClaudeCode

日程管理最烦的是什么？不是记不住，而是**记下来之后还要自己拆解、排期、设提醒**。如果这些脏活也能像改代码一样丢给 AI，生活会轻松很多。

这篇文章记录我刚刚做完的事：把**滴答清单（TickTick）**的 MCP 服务器接进**手机端的 Claude**，让 AI 能直接读写我的任务清单。全程浏览器操作。

先给结论：**手机 Claude App 里没有「添加 MCP」按钮，你需要去手机浏览器里配置连接器，配置完会自动同步到 App。**

---

## 1. 为什么要在手机端做这件事

桌面端 Claude 早就支持 MCP，给终端接个任务管理服务器不是什么新鲜事。但真正的日程管理场景，几乎全发生在**手机**上：

- 走在路上突然想到一件事，语音说一句就让 AI 记进清单
- 睡前躺在床上，问 Claude「明天有什么安排」
- 下课掏出手机，把老师刚布置的任务直接丢给 AI，让它拆成带截止时间的待办

这些场景里，电脑不在手边。所以关键在于——**让手机上的 Claude 也能用滴答清单**。

滴答清单官方提供了一个远程 MCP 服务器，不用本地跑 Node 服务，填个 URL 就能用：

> 🌐 [mcp.dida365.com](https://mcp.dida365.com)

---

## 2. 前置认知：为什么手机 App 里找不到「添加 MCP」按钮

很多人第一步就卡住：在手机 Claude App 里翻遍设置，都找不到添加 MCP 的入口。别怀疑自己找漏了，是**官方故意不放**。

原因很直白：MCP 服务器能读写你的数据，手机端直接弹授权不够安全。所以 Claude 要求 MCP 连接器走**浏览器 + OAuth 授权**流程，配置完成后才自动同步到手机 App。

这个思路来自 agentview.de 的一篇指南：

> 🌐 [agentview.de/zh/anleitung/mcp-mobile-einrichten](https://agentview.de/zh/anleitung/mcp-mobile-einrichten)

所以正确姿势是：**在手机浏览器里登录 claude.ai 配置连接器，然后回 App 里直接用。**

---

## 3. 动手配置：5 步接进手机 Claude

全程用手机 Safari / Chrome 即可，大约 3 分钟。

### 第 1 步：手机浏览器打开连接器页面

在手机浏览器打开：

```
https://claude.ai/customize/connectors
```

登录你的 Claude 账号。这个直达链接跳过了头像菜单，直接进连接器管理页。**免费版就能用**，免费额度包含 1 个自定义连接器。

### 第 2 步：添加自定义连接器

点击页面右上角的**加号**，选择「**添加自定义连接器**」。注意别选成「浏览连接器」——那是去官方精选库里挑的，滴答清单不保证在里面。

### 第 3 步：填写名称和 URL

| 配置项 | 填写内容                          |
| ------ | --------------------------------- |
| 名称   | 滴答清单（或`dida365`，随便起） |
| URL    | `https://mcp.dida365.com`       |

「高级设置」保持折叠不动，Claude 会在第一次调用工具时自动识别 OAuth。填完点「添加」。

### 第 4 步：完成 OAuth 授权

首次调用工具时，Claude 会弹出滴答清单的授权页面。用你的**滴答清单账号**登录并确认授权即可，之后 AI 就能代你操作清单了。

### 第 5 步：手机 App 里启用

打开手机上的 Claude App，在聊天框下方点**加号**，选「**连接器**」，勾选「滴答清单」。配置会自动同步，通常几秒内生效，不用重启 App。

---

## 4. 配好之后：自然的日程管理

连接之后，日程管理就从「动手操作 App」变成了「**说人话**」：

> **你**：明天下午要交作业，帮我记一下
> **Claude**：好的，已创建任务「交作业」，截止明天下午。
> **你**：这周五之前有哪些任务？
> **Claude**：（读取清单后列出，按截止时间排序）

更进阶的玩法：

- **语音记录**：想到什么直接语音输入，Claude 自动整理成带截止时间的任务
- **自动拆解**：说「下周准备线代期中考」，Claude 帮你拆成「复习第 1–3 章」「刷往年卷」「错题重做」，并排到清单里
- **智能提醒**：任务临近截止时问一句，Claude 直接汇报，不用你翻清单
- **双端同步**：手机上创建的每条任务，滴答清单 App 里同步出现，通知照常推送

---

## 5. 注意事项与避坑

- **保持同一浏览器**：OAuth 授权流程要在同一个浏览器标签页里走完，中途切换容易失败。
- **权限边界**：滴答清单 MCP 只能访问你授权范围内的清单内容，**看不到**你和 AI 的聊天文本。
- **免费额度**：Claude 免费版只允许 1 个自定义连接器。如果之前已经配过别的，需要先移除或升级订阅。
- **撤销访问**：在 claude.ai 的连接器列表里删掉即可，立即生效，滴答清单里的任务不受影响。
- **首次同步**：如果 App 里没出现连接器，注销账号重新登录一次，触发同步即可。
