# 🧠 ZJU 应付考核技巧：聪明地省时间

> **作者**：NeuraSailor × ClaudeCode

大学里有些东西是值得全力以赴的——比如核心专业课、比如你真正热爱的方向。但也有些东西……说白了就是刷个存在感。网课挂着、跑步打卡、形式化的考核——它们消耗时间，却几乎不产生价值。

我的态度很明确：**在保证自己做更有效的事的前提下，应付该应付的考核。** 这不是偷懒，是资源优化。

这篇文章分享几个我实际用过的方法。

---

## 1. 思想前提：不是偷懒，是优化

先想清楚一件事：你应付的到底是"考核"还是"学习"？

- **考核**是学校要求你做的事情——刷网课、跑打卡、凑学时。
- **学习**是你自己选择投入的事情——读论文、写代码、做项目。

很多时候这两者重合度很低。强制跑步打卡不会让你爱上跑步，挂着网课听天书也不会让你学懂一门课。

所以这篇的前提是：**你已经有了自己觉得更值得投入的事情。** 如果你的时间花得比刷网课更有价值，那应付考核就是理性的选择。反过来，如果你只是把应付考核省下的时间拿去刷短视频……那问题不在考核本身。

我自己判断的标准很简单：**如果做这件事的时间能给另一个更重要的事，我就把它自动化掉。**

比如我喜欢在跑步机上跑步，那操场打卡对我来说就是纯消耗——同样的运动效果，我宁愿在健身房完成，而不是在操场上为了凑里程绕圈。

---

## 2. 网课应付：OCS Desktop

> 🔗 下载：[docs.ocsjs.com/docs/app](https://docs.ocsjs.com/docs/app)

**OCS** 是 GitHub 上比较成熟的网课助手项目，支持超星学习通、智慧树、中国大学 MOOC等主流平台。它的核心能力：

- **自动播放视频**：静音后台挂机，不用守着屏幕
- **自动答题**：题库匹配 + 在线搜题，自动完成章节测验和考试（准确率取决于题库覆盖度，不要完全依赖）
- **多平台兼容**：一个工具覆盖大部分常见网课平台

OCS 有两个版本：

| 版本                            | 适用场景                                     |
| ------------------------------- | -------------------------------------------- |
| **OCS Desktop**（桌面端） | 一键启动，不用装浏览器插件，适合不想折腾的人 |
| **油猴脚本版**            | 装进 Tampermonkey/脚本猫，浏览器里自动运行   |

我个人推荐 OCS Desktop——下载、双击、登录网课、放着就行。不需要配浏览器环境，不用折腾脚本管理器。

> ⚠️ **注意**：自动答题的准确率做不到 100%，重要章节建议自己看一眼。另外，有些平台会检测脚本行为，建议不要 24 小时高强度挂机，模拟正常的学习节奏（白天挂着，晚上关掉）。

### 补充：MOOC 答案查询

> 🔗 答案站：[ginnnnnn.top/mooc](https://ginnnnnn.top/mooc)

OCS 能帮你挂视频，但章节测验和期末考试的答案不一定全覆盖。这个站点专门收录了各大 MOOC 平台的题库答案，可以直接搜索题目。

**但有一个重要原则：先自己做，再对答案。**

不是说教。纯粹从功利角度讲——

- 题目已经有人帮你整理了答案，你只需要**做完之后核对**，找出自己错在哪里。这是效率最高的学习方式——直接定位薄弱点，而不是漫无目的地翻课本。
- 如果直接抄答案，分数是拿到了，但考试的时候你还是不会。MOOC 的期末考通常不是线上监考，但你总得面对专业课考试——那时候可没有答案站。

所以理想流程是：**自己做完 → 对答案 → 搞懂错题 → 分数拿到 + 知识也到手。** 分数尽量拿满，但不要只拿分不拿知识。🔮

## 3. 体育跑步打卡：安卓虚拟机 + 虚拟定位

ZJU 的跑步打卡系统通常要求：在规定区域内、跑够一定里程、配速在合理范围内。

核心思路很简单：**在电脑上跑一个安卓虚拟机，用虚拟定位模拟校园位置，让跑步 App 以为你在操场上跑步。**

方法适用于**所有系统**

## 总结

| 考核类型     | 方案                         | 关键词             |
| ------------ | ---------------------------- | ------------------ |
| 网课刷课时   | OCS Desktop                  | 自动播放 + 搜题    |
| 体育跑步打卡 | 安卓模拟器 + 虚拟定位        | 通用、隔离、可恢复 |
| 思想前提     | 省下的时间拿去做更有价值的事 | 不要骗自己         |

最后再说一句：这篇文章的前提始终是"**你有更重要的事要做**"。如果你连那个"更重要的事"都不知道是什么，那也许先把考核老老实实做完，反而是最不坏的选择。

但如果你知道自己要什么——那就去做。不要让形式化的考核成为你的绊脚石。🔮
