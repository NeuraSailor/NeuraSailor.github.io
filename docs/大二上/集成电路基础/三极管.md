> [!note]
> 工作在什么区：先假设在放大区，$V_{CE}?>0.7$
> $I_{B}$ 是否大于 $I_{BS}=\frac{{V_{cc}-0.3}}{\beta R_{C}}$
> 计算电流等
> 叠加/戴维南

> [!important] 理解
> 1. 从 C 看，就是个恒流源，I_C 只受 B，E 影响，不受 C 外电路影响
> 2. BE 像一个阀门，V_{BE} 保持基本恒定，V_{BE}（V_B 升高或 V_E 降低）略微上升导致 I_B 急剧上升
