  $\dot{A}_\nu=\frac{\dot{V}_o}{\dot{V}_i}=\frac{1/j\omega C}{R+1/j\omega C}=\frac{1}{1+j\omega RC}=\frac{1}{1+jf/f_{H}}$
  $f_{H}=\frac{1}{2\pi\tau_{H}}=\frac{1}{2\pi RC}\text{高频转折频率}$
  ![[Pasted image 20251209192855.png|300]]

2. 高通电路：
  ![[Pasted image 20251209193019.png|200]]
  $\dot{A}_{v}=\frac{\dot{V}_{o}}{\dot{V}_{i}}=\frac{R}{R+1/j\omega C}=\frac{j\omega RC}{1+j\omega RC}=\frac{jf/f_{L}}{1+jf/f_{L}}$
  $f_{L}=\frac{1}{2\pi\tau_{L}}=\frac{1}{2\pi RC}\quad\text{低频转折频率}$

### 多级放大电路电压放大倍数的频率响应表达式

其中，$\dot{A}_{\nu}\approx\dot{A}_{\nu m}\prod_{k}\frac{jf/f_{Lk}}{1+jf/f_{Lk}}\prod_{i}\frac{1}{1+jf/f_{Hi}}$，

其中 $\frac{jf/f_{Lk}}{1+jf/f_{Lk}}$ 为低频段放大倍数；$\frac{1}{1+jf/f_{Hi}}$ 为高频段放大倍数
