!!! note
| 反馈类型         | 工作区域           | 典型电路                     | 是否需要输入       |
|------------------|--------------------|------------------------------|--------------------|
| 负反馈           | 线性区             | 放大器、滤波器、积分器等     | 是                 |
| 无反馈（开环）   | 非线性（饱和）     | 电压比较器                   | 是（两个输入）     |
| 正反馈           | 非线性（饱和）     | 迟滞比较器（施密特触发器）   | 是                 |
| 正反馈 + 选频网络 | 自激振荡           | [正弦波振振荡器](正弦波振振荡器)（如文氏电桥） | 否（自激）         |
