场效应晶体管是一种**电压控制电流型器件**，其工作电流主要由多数载流子的漂移运动形成，因此又称为**单极型晶体管**。

根据结构和制造工艺的不同，场效应管主要分为两大类：**结型场效应管（J-FET）**和**绝缘栅场效应管（MOS-FET）**。

### 场效应晶体管分类及偏置电压总结

| 场效应管类型                | 亚型 (极性/工作模式)      | 栅源电压 ($V_{GS}$) 要求 | 漏源电压 ($V_{DS}$) 要求 | $V_P$ 或 $V_T$ 极性判断 |
| :-------------------- | :---------------- | :----------------- | :----------------- | :----------------- |
| **结型场效应管 (J-FET)**    | N结型 (N-JFET)      | 负                  | 正                  | **$V_P < 0$ (负)**  |
|                       | P结型 (P-JFET)      | 正                  | 负                  | **$V_P > 0$ (正)**  |
| **绝缘栅场效应管 (MOS-FET)** | -                 | -                  | -                  | -                  |
|                       | **增强型** NMOS (E型) | 正                  | 正                  | **$V_T > 0$ (正)**  |
|                       | **增强型** PMOS (E型) | 负                  | 负                  | **$V_T < 0$ (负)**  |
|                       | **耗尽型** NMOS (D型) | 负（正）               | 正                  | **$V_P < 0$ (负)**  |
|                       | **耗尽型** PMOS (D型) | 正（负）               | 负                  | **$V_P > 0$ (正)**  |

**补充信息：**

- 场效应管的三个电极s（源极）、d（漏极）、g（栅极）与三极管的e（发射极）、c（集电极）、b（基极）相对应。
- 增强型 NMOS 管工作在放大区（恒流区、饱和区）的条件是：$V_{GS} > V_T$ 且 $V_{DS} \ge V_{GS} - V_T$。
- 耗尽型 NMOS 管工作在放大区的条件是：$V_{GS} > V_P$ 且 $V_{DS} \ge V_{GS} - V_P$（其中 $V_P$ 为夹断电压）。
- 场效应管的主要直流参数包括：开启电压 $V_T$、夹断电压 $V_P$、饱和漏极电流 $I_{DSS}$，以及直流输入电阻 $R_{GS(DC)}$（很大，约为 $10^7$ 到 $10^9$ 欧姆）。
- 增强型：$I_{D}=I_{DO}\left( \frac{V_{GS}}{V_{T}}-1 \right)^2$
- 耗尽型：$I_{D}=I_{DSS}\left( 1-\frac{V_{GS}}{V_{P}}\right)^2$

!!! note "- 讲解"
你好！很高兴能以老师的角色引导你深入学习场效应管（FET）。既然你对三极管（BJT）有较好的掌握，那我们就可以通过**对比学习**的方式，帮你把混淆的概念理清楚。

### 一、 核心概念对比：从"电流控制"到"电压控制"

首先，你要明确场效应管与三极管在本质上的区别：
*   **控制原理**：三极管是电流控制电流器件（用 $I_B$ 控制 $I_C$），而**场效应管是电压控制电流型器件**。它利用栅源电压 $V_{GS}$ 产生的电场来控制漏极电流 $I_D$。
*   **载流子类型**：三极管利用电子和空穴两种载流子（双极型），而场效应管主要靠一种载流子（多数载流子）运动形成电流，所以又叫**单极型晶体管**。
*   **管脚对应**：为了方便分析，你可以将 FET 的三个极与 BJT 进行类比：**栅极 (g) 对应基极 (b)，漏极 (d) 对应集电极 (c)，源极 (s) 对应发射极 (e)**。

### 二、 场效应管的分类（不再混淆的关键）

场效应管的种类较多，我们可以通过下表理清它们的特性：

1.  **结型场效应管 (JFET)**：分为 N 沟道和 P 沟道。它的特点是"天生导通"，必须加反向电压才能使其关断。
2.  **绝缘栅场效应管 (MOSFET)**：这是目前应用最广的类型，分为：
*   **增强型 (E型)**：$V_{GS}=0$ 时没有导电沟道，必须施加电压达到**开启电压 $V_T$** 后才会导通。
*   **耗尽型 (D型)**：制造时已预留沟道，即使 $V_{GS}=0$ 也能导电，施加电压达到**夹断电压 $V_P$** 时才消失。

### 三、 分析方法：三个工作区与偏置电路

分析场效应管电路时，第一步通常是确定它工作在哪个区域：

*   **夹断区（截止区）**：当 $V_{GS} < V_T$（增强型）或 $V_{GS} < V_P$（耗尽型）时，沟道消失，电流 $I_D \approx 0$。
*   **可变电阻区**：当沟道开启且 $V_{DS}$ 较小时，管子相当于一个由 $V_{GS}$ 控制的电阻。
*   **放大区（恒流区/饱和区）**：这是放大电路关注的重点。条件是 **$V_{GS} > V_T$ 且 $V_{DS} \geq V_{GS} - V_T$**。此时 $I_D$ 主要受 $V_{GS}$ 控制，体现出恒流特性。

**静态工作点 (Q点) 的计算分析方法：**
1.  **估算法**：联立电流方程（如 $I_D = I_{DSS}(1 - \frac{V_{GS}}{V_P})^2$）与回路方程（如 $V_{GS} = V_G - I_D R_s$）进行求解。注意解方程组会得到两个解，必须根据 $V_{GS}$ 是否能让管子导通来舍去不合理的一组。
2.  **验证合理性**：求出结果后，必须验证是否满足 $V_{DS} > V_{GS} - V_T$（或 $V_P$），以确保管子确实工作在放大区。

### 四、 场效应管的独特优势

与三极管相比，场效应管有一个巨大的优点：**直流输入电阻极高 ($10^7 - 10^9 \Omega$)**。这意味着它几乎不从信号源抽取电流，只需提供电压即可工作。因此，场效应管的偏置电路通常有其特点，如**自偏压电路**（仅适用于耗尽型和 JFET）和**分压式自偏压电路**。

***

**老师小结：**
如果把三极管比作一个**需要你用力推（注入电流 $I_B$）**才能打开的水龙头；那么场效应管就像一个**电磁阀**，你只需要**施加一个电压信号（$V_{GS}$）**，它就会通过内部的电场力去调节水流（$I_D$）的大小，而不需要你持续地消耗控制信号的电能。
