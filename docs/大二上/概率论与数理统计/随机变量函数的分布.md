找到 $F_x(x) 与 F_y(y)$ 的关系

$F_Y(y) = P(Y \leq y) = P(g(X) \leq y)$.

$\text{由于 } g \text{ 单调增，} g(X) \leq y \Longleftrightarrow X \leq h(y) \text{，其中 } h = g^{-1} \text{。因此：} F_Y(y) = P(X \leq h(y)) = F_X(h(y)).$

$\therefore f_Y(y) = f_X(h(y)) \cdot |h'(y)|$

### 结论

1. $Y = aX + b \sim N(a\mu + b, a^2 \sigma^2)$
2. $y = g(x)$ 单调增，反 function $x = h(y)$, 则 y 的密度 function $f_y(y) = f_x(h(y)) |h'(y)|$
