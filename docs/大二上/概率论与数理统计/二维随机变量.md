## 分布律

   能唯一确定边际分布律
2. 边缘分布律
3. 条件分布律

## 分布函数

### 联合分布

$F(x,y) = P(X \leq x, Y \leq y)$

### 边缘分布

$F_X(x) = P(X \leq x) = P(X \leq x, y < +\infty) = F(x, +\infty)$

### 条件分布

$F_{X|Y}(x|y) = P(X \leq x | Y = y)$（理解：Y=y 即为 $y < Y \leq y + \delta$）

## 概率密度 function

概率密度 function $f_X(x)$ 是分布 function $F_X(x)$ 的导数，即 $f_X(x) = \frac{d}{dx} F_X(x)$。

#### 联合分布

联合概率密度 function $f_{X,Y}(x,y)$ 是联合分布 function $F_{X,Y}(x,y)$ 的二阶偏导数：$f_{X,Y}(x,y) = \frac{\partial^2}{\partial x \partial y} F_{X,Y}(x,y)$

### 边际分布

边际概率密度 function 可通过积分得到，例如 $f_X(x) = \int_{-\infty}^{+\infty} f_{X,Y}(x,y) dy$。

### 条件分布

条件概率密度 function 定义为 $f_{X|Y}(x|y) = \frac{f_{X,Y}(x,y)}{f_Y(y)}$，需满足 $f_Y(y) > 0$。

### 性质

1. $\int_{-\infty}^{+\infty} \int_{-\infty}^{+\infty} f(x,y) dxdy = 1$【归一性】
2. $f(x,y) \geq 0$
3. 连续点处 $f(x,y) = \frac{\partial^2 F(x,y)}{\partial x \partial y}$【密度与分布 function 关系】
4. $P\{(X,Y) \in D\} = \iint_D f(x,y) dxdy$【联合分布】
5. $F(x,y) = \int_{-\infty}^x \int_{-\infty}^y f(u,v) du dv$
