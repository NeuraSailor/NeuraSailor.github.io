统计量：不含任何未知参数的样本的 function

作用：利用样本的统计量代替总体的特征

1. 样本均值
   $\bar{X} = \frac{1}{n} \sum_{i=1}^n X_i$
2. 样本方差
   $S^2 = \frac{1}{n-1} \sum_{i=1}^n (X_i - \overline{X})^2$
3. 样本 $k$ 阶（原点）矩：
   $A_k = \frac{1}{n} \sum_{i=1}^n X_i^k \quad (k=1, 2, \cdots)$
4. 样本 $k$ 阶中心矩：
   $B_k = \frac{1}{n} \sum_{i=1}^n (X_i - \bar{X})^k \quad (k=2, \cdots)$

特别的：
**$(n-1)S^2 = nB_2 = \sum_{i=1}^n (X_i - \bar{X})^2$**

6. 独立性：X1, X2, …, Xn 是相互独立的随机变量：无协方差
7. $\implies$ 样本方差/均值是总体方差/均值的无偏估计；
