随机变量 X: 将随机试验的结果对应到数的实值 function

分为：离散型、连续

## 离散型随机变量

> [!abstract]-
> 先确定 X 的可能取值
> 再求其概率分布 X~B(n, p)/P(λ)
>
![方差，相关性#六大分布](方差，相关性#六大分布)

概率分布率 P（X=x₁）=p₁【一组概率】

### 0-1 分布

贝努利实验：只有两种结果

n 重贝努利实验：两种结果、次次独立

### 二项分布

1. 各试验独立
2. 一次试验有两方面
3. X 为某方面发生次数

X~B(n, p)

$C_n^k p^k (1-p)^{n-k}$

### 泊松分布

稀有分布

对二项分布取极限情况

有：X~P(λ)

$P(x=k) = \frac{e^{-\lambda} \lambda^k}{k!}$ 其中 $\lambda = np$

### 超几何分布

等可能模型

### 几何分布

随机变量 X 表示到事件发生为止的试验次数

$P\{X=k\} = p(1-p)^{k-1}$
