参数估计是利用样本资料对总体未知参数给出估计的方法，分为**点估计**和**区间估计**两类。参数是反映总体某方面特征的量，例如正态分布总体中优秀率是 $\mu$ 和 $\sigma^2$ 的 function。

## 1. 参数的点估计 (Point Estimation)

点估计问题旨在构造合适的统计量 $\hat{\theta}(X_1, \dots, X_n)$ 来估计未知参数 $\theta$，称 $\hat{\theta}$ 为参数 $\theta$ 的点估计量。常用的方法包括矩估计法和极大似然估计法。

### 1.1 矩估计法 (Method of Moments)

矩估计的基本步骤包括求总体 $m$ 阶矩关于 $m$ 个参数的 function，求各参数关于前 $m$ 阶矩的反 function，最后以样本各阶矩代替总体各阶矩。

#### 性质

1. **矩估计不涉及总体分布**，但矩估计量可能不唯一。

#### 做法

1. 假设已知总体量（总期望、方差等），求解所求矩估计量 $\hat{y}$
2. 用样本量代替前面假设的总体量
3. 基本样本 $X_i$ 估计总体 $x_i$：
   1. $\mu_1 = E(X) \overset{P}{\to} \bar{X} = A_1$
   2. $Var(X) = v_2 \overset{P}{\to} B_2 = \frac{1}{n} \sum_{i=1}^n (X_i - \bar{X})^2 = A_2 - \bar{X}^2$

### 1.2 极大似然估计法 (Maximum Likelihood Estimation, MLE)

极大似然原理是选择使得样本观察值出现的概率（离散型）或概率密度（连续型）最大的参数值 $\hat{\theta}$。该概率或概率密度的乘积 function 称为**似然 function $L(\theta)$**。求解极大似然估计通常通过最大化**对数似然 function $l(\theta) = \ln L(\theta)$** 来进行。

#### 性质

1. 极大似然估计不变性

### 典型估计

| 整体 | $\mu$ | $\sigma^2$ |
| --- | --- | --- |
| 矩估计 | $\bar{X}$ | $B_2$ |
| 极大似然估计 (正态分布下) | $\bar{X}$ | $B_2$ |

## 2. 估计量的评价准则

评价估计量好坏有四条准则：**无偏性准则**、**有效性准则**、**均方误差准则**、**相合性准则**。

### 无偏性

若估计量 $\hat{\theta}$ 满足期望 $E(\hat{\theta}) = \theta$，则称 $\hat{\theta}$ 是 $\theta$ 的无偏估计量。无偏性保证了估计没有系统误差。例如，样本均值 $\bar{X}$ 和样本方差 $S^2$ 分别是 $\mu$ 和 $\sigma^2$ 的无偏估计。

### 有效性

$Var(\hat{\theta}) \overset{无偏}{=} E(\hat{\theta} - \theta)$

对于两个**无偏**估计量，如果其中一个的方差 $Var(\hat{\theta})$ 对一切 $\theta$ 成立且更小，则称其更有效。

### 均方误差 (MSE)

$Mse(\hat{\theta}) = E(\hat{\theta} - \theta)^2$

若 $\hat{\theta}$ 是 $\theta$ 的无偏估计，则均方误差等于方差，即 $Mse(\hat{\theta}) = Var(\hat{\theta})$。

所以均方误差主要用于有偏量的误差比较

## 3. 区间估计 (Interval Estimation)

区间估计是给出两个统计量 $\hat{\theta}_L$ 和 $\hat{\theta}_U$，使随机区间 $[\hat{\theta}_L, \hat{\theta}_U]$ 以一定的可靠程度 $1-\alpha$ 盖住未知参数 $\theta$。$1-\alpha$ 称为**置信水平**或**置信度**。

### 枢轴量法

构造置信区间的常用方法是枢轴量法。**枢轴量 $G(X_1, \dots, X_n; \theta)$** 是样本和待估参数 $\theta$ 的 function，其分布完全已知，且**不依赖于未知参数 $\theta$**。通过确定常数 $a, b$ 使 $P(a < G < b) = 1 - \alpha$，然后通过不等式变换即可得到 $\theta$ 的置信区间 $[\hat{\theta}_L, \hat{\theta}_U]$。

### 正态总体参数的区间估计

在正态总体 $N(\mu, \sigma^2)$ 下，构造 $\mu$ 或 $\sigma^2$ 的置信区间时会使用特定的枢轴量：

- **估计 $\mu$（$\sigma$ 已知）：** 枢轴量是 $Z = \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \sim N(0, 1)$。
- **估计 $\mu$（$\sigma$ 未知）：** 枢轴量是 $T = \frac{\bar{X} - \mu}{S/\sqrt{n}} \sim t(n-1)$。
- **估计 $\sigma^2$（$\mu$ 未知）：** 枢轴量是 $\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$。
