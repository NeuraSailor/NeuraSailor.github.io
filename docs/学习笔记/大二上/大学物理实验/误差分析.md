### 误差分布
#### 正态分布
真值: $μ=lim \frac{1}{n} \sum_{i=1}^{n} x_i$ $\sigma = lim_{n \to \infty} \sqrt{\frac{1}{n}\sum_{i=1}^{n}(x_i - \mu)^2}$ 1
平均值: $\bar x = \frac{1}{n}\sum_{k=1}^{n} x_k$ 一般 $6 \le n \le 10$

单次测量值的标准偏差: $s(x) = \sqrt{\frac{1}{n-1}\sum_{k=1}^{n}(x_k - \mu)^2} = \sqrt{\frac{1}{n-1}\sum_{k=1}^{n}(x_k - \bar x)^2}$

平均值的标准偏差: $u_A(\bar x) = s(\bar x) = |\bar x - \mu| = \sqrt{\frac{1}{n(n-1)}\sum_{k=1}^{n}(x_k - \bar x)^2}$
