磨镜者公式：薄透镜

1. 球面镜反射：
  $\frac{1}{S}+\frac{1}{S^{\prime}}=\frac{1}{f}$
  $f=R/2$
  $\text{横向放大率:}\quad m=\frac{P^{\prime}Q^{\prime}}{PQ}=\frac{y^{\prime}}{y}=-\frac{S^{\prime}}{S}$

2. 单球面折射成像
  $\frac{n_1}{S}+\frac{n_2}{S^{\prime}}=\frac{n_2-n_1}{R}$

3. 薄透镜成像
  磨镜者公式：$\frac{1}{f}=(n-1)(\frac{1}{R_1}-\frac{1}{R_2})$
  薄透镜成像公式(高斯公式)：$\frac{1}{S}+\frac{1}{S^{\prime}}=\frac{1}{f}$
  横向放大率：$m=\frac{y^{\prime}}{y}=-\frac{S^{\prime}}{S}$

4. 放大镜
  角放大率：$m_\theta=\frac{\theta^{\prime}}{\theta}=\frac{25cm}{f}$

**正负性：**

5. 物距相距 s，s':
  1. 物与入射光线在界面的同侧，S为正，实物；反之，S为负，虚物。
  2. 像与出射光线在界面的同侧，S′为正， 实像；反之，S′为负，虚像。

6. 曲率半径 R、焦距 f：<font color="#ffff00">曲率中心 C 与出射光线在界面的同侧</font>，R、f 为正 (如：凹球面镜)，反之为负 (如：凸球面镜)。

7. 透射：凸透镜：f 正
