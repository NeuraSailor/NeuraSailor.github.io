## 定理

### 基尔霍夫辐射定律

在同样的温度下，各种不同的物体对相同波长的单色辐出度与单色吸收系数之比都相等

$\frac{M_{1\lambda}}{\alpha_{1\lambda}}=\frac{M_{2\lambda}}{\alpha_{2\lambda}}=\cdots=\frac{M_{B\lambda}}{\alpha_{B\lambda}}=M_{B\lambda}$

**好的吸收体也是好的辐射体。黑体是完全的吸收体，因此也是理想的辐射体**

### Stefan（斯忒藩）-Boltzman（玻耳兹曼）Law

$M_B(T)=\sigma T^4$

$M_B(T)$：黑体的辐射出射度 (单位时间单位面积辐射能)

T：黑体的绝对温度

σ：斯忒藩-玻尔兹曼常数

### Wien（维恩）位移 Law

$T\lambda_{\mathrm{m}}=b$

λm ：光谱辐射出射度达到峰值时对应的波长

T：黑体的绝对温度

b：维恩位移常数

## M.Plank的能量子假设

1. 频率为ν的谐振子(黑体腔壁原子)只能取下列不连续能量：$\varepsilon_{n} = n h \nu \quad n = 0, 1, 2, …$
2. 谐振子只能发射或吸收等于一个能量子的能量：$\Delta \varepsilon = \Delta n h \nu$
