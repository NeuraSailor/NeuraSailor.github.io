## $M = max(X,Y)$ 和 $N = min(X,Y)$ 的分布

> [!note]
> 1. F(x) = P(X≤x)
> 2. P(…) = …P(max<u)…P(min>v)
> 3. 其中 P(max<u) = 独立 = $P(x_1<u) P(x_2<u) \dots = F_{X_1}(u) F_{X_2}(u) \dots$
> 4. P(min>v) = 独立 = $P(y_1>v) P(y_2>v) \dots = (1-F_{y_1}(v))(1-f_{y_2}(v)) \dots$
> 5. 分布 function F(x) 求导得到密度 function

设 $X,Y$ 是两个相互独立的随机变量，它们的分布 function 分别为 $F_X(x)$ 和 $F_Y(y)$，求 $M,N$ 的分布 function $F_{max}(z)$ 和 $F_{min}(z)$。

$M = max(X,Y)$ 的分布 function 为：

$F_{max}(z) = P(M \leq z)$
$= P(X \leq z, Y \leq z)$
独立
$= P(X \leq z) P(Y \leq z)$

> $F_{max}(z) = F_X(z) F_Y(z)$

$N = min(X,Y)$ 的分布 function 为：

$F_{min}(z) = P(N \leq z) = 1 - P(N > z)$
$= 1 - P(X > z, Y > z)$
独立
$= 1 - P(X > z) P(Y > z)$

> $F_{min}(z) = 1 - (1 - F_X(z))(1 - F_Y(z))$
