## 均匀分布

### 联合密度 function

概率密度 function 为 $f(x,y) = \frac{1}{S_D}, (x,y) \in D$

### 联合分布 function

对密度 function 二重积分

### 边际密度 function

降维了

$f_X(x) = \int_{-\infty}^{+\infty} f(x,y) dy$

$f_Y(y) = \int_{-\infty}^{+\infty} f(x,y) dx$

### 条件分布 function

$F_{X|Y} = \lim_{\varepsilon \to 0^+} \frac{P(X \leq x, y < Y \leq y + \varepsilon)}{P(y < Y \leq y + \varepsilon)} = \lim_{\varepsilon \to 0^+} \frac{\int_{-\infty}^x du \int_y^{y+\varepsilon} f(u,v) dv}{\int_y^{y+\varepsilon} f_Y(v) dv}$

也可以是 $F_{X|Y}(x|y) = \int_{-\infty}^x f_{X|Y}(u|y) du = \int_{-\infty}^x \frac{f(u, y)}{f_Y(y)} du$

### 条件密度 function

$f_{Y|X}(y|x) = \frac{f(x,y)}{f_X(x)}$
