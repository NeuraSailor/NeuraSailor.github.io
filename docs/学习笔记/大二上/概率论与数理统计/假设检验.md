## 一、随机变量数字特征的定义和含义

| 数字特征 | 符号 | 含义 |
| --- | --- | --- |
| **数学期望**（期望/均值） | $E[X]$ | 随机变量取值的**平均水平**，刻画随机变量的集中位置。 |
| **方差** | $\text{Var}(X)$ 或 $D(X)$ | 衡量随机变量 $X$ 取值相对于其均值 $E[X]$ 的**分散程度**。方差越大，分散程度越大。 |
| **协方差** | $\text{Cov}(X, Y)$ | 衡量两个随机变量 $X$ 和 $Y$ 之间的**联合变异性**，即它们**线性关系**的程度和方向。 |
| **相关系数** | $\rho_{XY}$ | 协方差的标准化形式，衡量 $X$ 和 $Y$ 之间**线性关系紧密程度**的无量纲量。定义为 $\boldsymbol{\rho_{XY} = \frac{\text{Cov}(X, Y)}{\sqrt{\text{Var}(X)\text{Var}(Y)}}}$。 |

## 二、独立性、相关性、期望、方差和协方差的一般关系

### 1. 期望和方差的关系（线性组合）

数学期望具有**可加性**，无论变量是否独立：

- **期望的加法性质：** $\boldsymbol{E}[X \pm Y] = E[X] \pm E[Y]$。这一性质可以推广到任意有限个随机变量线性组合的情况。

方差在计算和的方差时，必须考虑协方差项：

- **方差的加法性质：** $\text{Var}(X \pm Y) = \text{Var}(X) + \text{Var}(Y) \pm 2\text{Cov}(X, Y)$。

### 2. 独立性与期望的关系

- **独立性推出期望可乘性：** 如果 $X$ 与 $Y$ **相互独立**，则**乘积的期望等于期望的乘积**：$\boldsymbol{E}[XY] = E[X]E[Y]$。
  - **注意：** 虽然 $E[XY] = E[X]E[Y]$ 通常是独立时成立，但并非只有独立这一个条件才能使该等式成立，反之不一定独立。

### 3. 独立性与协方差/相关性的关系（核心关系）

独立性与不相关性之间的关系是单向推导的：

- **独立性 $\Rightarrow$ 不相关性：** 如果 $X$ 和 $Y$ **相互独立**，则它们一定**不相关**。
  - **数学体现：** 独立性导致 $E[XY] = E[X]E[Y]$，从而协方差 $\boldsymbol{\text{Cov}(X, Y) = 0}$。同时，相关系数 $\boldsymbol{\rho_{XY} = 0}$。
- **不相关性 $\not\Rightarrow$ 独立性：** 若 $X$ 与 $Y$ **不相关**（即 $\text{Cov}(X, Y) = 0$），则它们**却不一定独立**。
  - 协方差为 0 仅意味着变量之间**没有线性关系**。在一般情况下，可能存在非线性依赖关系，因此不独立。
- **相关性 $\Rightarrow$ 不独立性：** 若 $X$ 与 $Y$ **相关**（即 $\text{Cov}(X, Y) \ne 0$ 或 $\rho_{XY} \ne 0$），则它们一定**不独立**。

### 4. 独立性与方差的关系

- **独立性简化方差计算：** 如果 $X$ 与 $Y$ **相互独立**（或两两独立），则它们的和或差的方差公式可以简化，**协方差项为零**：$\boldsymbol{\text{Var}(X \pm Y) = \text{Var}(X) + \text{Var}(Y)}$

## 三、正态分布（特殊情况）下的关系

正态分布（特别是多元正态分布）具有特殊的、强大的性质。

### 1. 独立性和不相关性等价

- 对于服从**二维正态分布**的随机变量 $X$ 和 $Y$，**不相关性（协方差为零或 $\rho_{XY}=0$）是相互独立的充要条件**。
- 这一结论推广到 $n$ 维正态变量：它们相互独立的充要条件是它们**两两不相关**。
  - 这意味着在正态分布家族中，**线性不相关就等同于完全独立**。

### 2. 线性组合的分布保持性

- **线性组合的正态性：** 独立的正态变量的线性组合（和、差等）**仍然服从正态分布**。

### 3. 正态分布参数与数字特征的对应

- 对于正态分布 $\boldsymbol{X \sim N(\mu, \sigma^2)}$，其两个参数 $\mu$ 和 $\sigma^2$ **恰好分别就是其数学期望 $E[X]$ 和方差 $\text{Var}(X)$**。
- 二维正态分布的分布完全由各自的均值、方差以及它们的相关系数（体现在协方差矩阵中）所确定。
