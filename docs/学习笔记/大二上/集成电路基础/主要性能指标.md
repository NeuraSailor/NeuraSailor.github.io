1. 电压增益：$A_{v}=\frac{\dot{V}_{o}}{\dot{V}_{i}}$ **电压放大能力**
2. 开路电压增益 $A_{vo}=\frac{\dot{V}_{oo}}{\dot{V}_{i}}$（output，open）
3. 源电压（source，$V_{s}$）增益 $A_{vs}=\frac{\dot{V}_o}{\dot{V}_s}$
4. 分贝：取对数 $A_{\nu}(dB)=20\lg(V_{o}/V_{i})$

5. 输入阻抗：从放大电路输入端看进去的等效电阻 $R_{i}=\frac{V_{i}}{I_{i}}$ **信号在输入回路的传输效率**。<br>输入阻抗越大，Vin 无限接近信号源本来的电压 Vs
6. 输出电阻 $R_{0}$：**反映了放大电路带负载的能力**。<br>R 0越小，则放大电路带负载能力越强，电路输出越接近恒压源输出。$R_{o}=\frac{V_{o}^{^{\prime}}}{I_{o}^{^{\prime}}}\mid_{V_{s}=0,R_{L}=\infty}$
