## 三极管
三种组态的三极管的放大电路动态分析：
特征：大小（数量级）关系主要取决于表达式中β系数在分子还是分母

|        | 电压增益      | 输入电阻    | 输出电阻              | 特点            | 用途        |
| ------ | --------- | ------- | ----------------- | ------------- | --------- |
| 共射(CE) | 反相，电压增益大  | 较大(几千欧) | 较大(R<sub>c</sub>) | 既有电压放大和电流放大作用 | 应用广泛，中间级  |
| 共集(CC) | 同相，近似为1   | 最大      | 最小                | 输入电阻高、输出电阻低   | 阻抗变换或电流放大 |
| 共基(CB) | 同相，电压增益较大 | 最小(几十欧) | 较大(R<sub>c</sub>) | 频率特性好         | 宽频或高频放大电路 |

| 共集组态 (CC)                                                             | 性能指标                                           | 共射组态 (CE)                                             |
| :-------------------------------------------------------------------- | :--------------------------------------------- | :---------------------------------------------------- |
| **$A_v = \frac{(1+\beta) R'_L}{r_{be} + (1+\beta) R'_L}$** (近似为 1，同相) | **电压增益** ($A_v = \frac{\dot{V}_o}{\dot{V}_i}$) | **$A_v = -\beta \frac{R_c // R_L}{r_{be}}$** (反相，增益大) |
| **$R_i = R_b // [r_{be} + (1+\beta) R'_L]$** (最大)                     | **输入电阻** ($R_i$)                               | **$R_i = R_{b1} // R_{b2} // r_{be}$** (较大)           |
| **$R_o = \frac{r_{be} + R_b // R_s}{1+\beta} // R_e$** (最小)           | **输出电阻** ($R_o$)                               | **$R_o \approx R_c // r_{ce}$** (近似 $R_c$) (较大)       |

**形象化理解：**

如果将放大电路比作水管系统，**共射组态**就像是一个标准的水泵，能提供很大的压力（电压增益）和一定的流量（电流增益），但它对进水管（输入阻抗）和出水管（输出阻抗）都有中等的要求。**共集组态**（射极跟随器）就像是一个匹配器或缓冲器，它的作用不是提高压力，而是让你能从一个高压力源（高输入阻抗）顺利地驱动低压力的设备（低输出阻抗），实现**阻抗匹配**，同时水流的速度（信号的电压）基本保持不变 ($A_v \approx 1$)。**共基组态**则像是一个要求极高压输入（低输入阻抗）但能应对高速水流（高频特性好）的喷射器，具有很大的压力提升能力。

## 场效应管

|组态|电压增益|输入电阻|输出电阻|特点|用途|
|:--|:--|:--|:--|:--|:--|
|**共源 (CS)**|**反相**，电压增益大 ($A_v = -g_m R'_L$)|**最大** (由 $R_{g}$ 决定，通常很高)|较大 (近似 $R_d$)|**输入电阻极高**，具有电压放大作用|**常作为基本电压放大级**|
|**共漏 (CD)**|**同相**，近似为 **1** ($A_v \approx 1$)|**最大** (由 $R_{g}$ 决定，通常很高)|**最小** (近似 $\frac{1}{g_m}$)|输入电阻极高，输出电阻极低；称为**源极跟随器**|**阻抗变换** (或驱动低阻负载)|
|**共栅 (CG)**|**同相**，电压增益较大 ($A_v = g_m R'_L$)|**最小** (近似 $\frac{1}{g_m}$)|较大 (近似 $R_d$)|具有较大的电压增益|宽频或高频应用（对应于BJT的共基组态）|

|性能指标|共源组态 (CS)|共漏组态 (CD) （源极跟随器）|共栅组态 (CG)|
|:--|:--|:--|:--|
|**电压增益** ($A_v$)|**$A_v = -g_m R'_L$** (反相，增益大)|**$A_v = \frac{g_m R'_L}{1 + g_m R'_L}$** (近似为 1，同相)|**$A_v = g_m R'_L$** (同相，增益较大)|
|**输入电阻** ($R_i$)|**$R_i = R_{g1} // R_{g2}$** (最大，通常很高)|**$R_i = R_{g1} // R_{g2}$** (最大，通常很高)|**$R_i = \frac{1}{g_m} // R_s$** (最小)|
|**输出电阻** ($R_o$)|**$R_o \approx R_d$** (较大)|**$R_o = \frac{1}{g_m} // R$** (源极电阻) (最小)|**$R_o \approx R_d$** (较大)|
