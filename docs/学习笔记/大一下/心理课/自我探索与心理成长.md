- 埃里克森人格发展八阶段理论

    婴儿期(0-1.5岁) 基本信任与不信任的心理冲突

    儿童期 (1.5-3岁) 自主与害羞(或怀疑)的冲突

    学龄初期(3-6岁) 主动对内疚的冲突

    学龄期(6-12岁) 勤奋对自卑的冲突

    青春期(12-18岁) 自我同一性与角色混乱的冲突

    成年早期(18-40岁) 亲密对孤独的冲突

    成年期(40-65岁) 繁衍对自我专注、停滞的冲突

    成熟期(65岁以上) 自我整合与绝望期的冲突

- 马勒“分离个体化”理论

    |   |   |   |
    |---|---|---|
    |阶段|年龄范围|状态|
    |第一阶段|0-2个月|自闭阶段——混沌状态|
    |第二阶段|2-6个月|共生阶段——自恋萌芽|
    |第三阶段|6-24个月|分离——个体化阶段——心理独立|
    |第四阶段|24-36个月|建立客体恒常性|

    幼儿能维持对母亲及其他一切的稳定形象

    足够好的妈妈, 足够好的世界, 足够好放自己

- 玛格丽特·马勒 分离个体化理论

    |   |   |   |   |
    |---|---|---|---|
    |时间|婴儿的分离个体化||青春期的分离个体化|
    |孵化期(6-10 个月)|从和母亲的融合共生开始孵化 开始在怀里挣扎,想看清母亲|开始学会坐、爬 抓妈妈|需要父母的关心和帮助 “不求不助、有求必应”|
    |实践期(10-16 个月)|离开母亲的怀抱 蹒跚学步、喜欢看陌生人|躲猫猫 “躲藏是一种乐 趣,但不被找到 则是一种灾难”|叛逆独特性 寻找小团体、亚文化的认同|
    |整合期(16- 24个月)|把独立、亲近、疏远整合起来 孩子欲拒还迎,母亲情绪稳定|小毛毯、洋娃娃 过渡性客体|游戏、爱好的能力|
    |客体永恒期 (24-36|现实母亲:整合母亲的好坏两面，接受母亲的暂时离场|自己玩一会|独处的能力、 调节情绪、接纳 的能力|
