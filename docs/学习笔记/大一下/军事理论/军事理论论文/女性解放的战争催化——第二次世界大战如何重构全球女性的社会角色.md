# Abstract：
第二次世界大战是全球女性社会角色重构的重要催化剂。战争期间，大量男性参军导致劳动力短缺，迫使女性广泛进入制造业、工程、科研等传统男性主导领域。各国政府通过宣传、立法等手段动员妇女加入劳动力市场，塑造了“强壮、独立、爱国”的女性新形象。尽管战后部分女性回归家庭，但女性劳动参与率显著提升，经济独立意识增强。更重要的是，二战积累的就业经验和自信心，促进了战后女性平权和民权运动，为争取平等工资、参与社会决策奠定了坚实基础。本文通过对二战对于女性的经济角色、社会形象及其长期影响的分析，揭示二战对全球女性解放进程的深远影响。

# 1.二战期间女性经济角色的转变
## 1.1劳动力参与率的大幅提升*
### 1.1.1男性生产力的迫切需求
以二战时期的美国为例，在战争时期，美国面临极其严重的劳动力短缺问题。**大量适龄男性参军是造成劳动力短缺的主要原因**。战争时期，美国征兵制度经过4次调整，分别是：1940年9月：首个和平时期征兵法案（《伯克-沃兹沃思法案》）要求21-35岁男性登记，授权征召90万人。1941年8月：珍珠港事件前，法案以微弱优势通过，延长服役期至战争结束。1942年：年龄范围扩展至18-45岁，并实施七轮大规模征兵登记，覆盖1877-1924年出生的男性。1943年：短暂将征兵上限提高至65岁，但实际征召集中于18-45岁群体。至战争结束时，**5000万男性完成登记，超1000万人被征召入伍，另有600万志愿参军者**，总兵力达1600万。这导致**4400万适龄男性几乎全部被动员**【1】
### 1.1.2 美国女性参与劳动率的提升
在二战爆发前，社会普遍认为女性的主要职责在于家庭和照料子女，参与公共经济活动的比例非常低。然而，随着战争的到来，传统劳动力市场出现巨大缺口，迫使广大女性走出家庭，投身各行各业。根据Claudia Goldin的研究，1940年代成为已婚女性劳动力参与率的显著转折点，许多女性在战争期间进入制造业、服务业和其他公共部门工作，从而推动了美国整体就业率的提高。同时，这一时期的女性不仅承担起生产任务，还在管理、文秘等职能部门中发挥了重要作用，体现了女性在经济领域多样化能力的提升。

## 1.2 女性在战争中扮演的角色
男性劳动力的短缺造成了对女性劳动力的大量需求。战争对男性劳动力的消耗客观上推动了女性在社会中扮演更多角色。以下对女性在战争中突破性别刻板印象，扮演的新角色做一个简单的梳理。
1. 参军：约35万女性加入陆军妇女军团（WAAC）、海军妇女预备队（WAVES）等，担任机械师、密码员、飞行护士等，部分精英如WASP飞行员执行飞机运输任务。最具代表意义的有：杰奎琳·科克伦（Jackie Cochran）推动女性飞行员参战，打破“飞行属于男性”的刻板印象。【2】![](../../assets/20250509145924863.png)

2. 制造业：随着1600万美国男性参军，女性成为军工生产的核心力量。220万美国女性进入工厂，承担起焊接、铆接、机械操作等传统男性工种。以“铆工罗茜”为标志的群体日均工作10-12小时，创造了战时生产的奇迹，美国女性在1942-1945年间生产了30万架飞机和1000万吨船舶【2】

3. 工程设计和科研领域：绘图室中女性工程师占比达35%，参与B-29轰炸机等尖端武器设计。工业实验室出现女性物理学家和化学家团队，优化弹药配方和金属材料。
## 1.3 女性经济角色的提升
- **行业突破**：女性进入传统男性主导的飞机制造（占比达24.4%）、交通运输、金属加工等领域，部分工厂甚至被称为“妇女的领域”。
- **结构变化**：已婚女性就业比例从战前的14%升至1944年的23%，650万女性首次进入劳动力市场，其中45%在战后仍留在制造业。【2】
# 2.二战中社会和文化中女性形象的再造效应
## 2.1 宣传动员的方式
### 2.1.1 利用宣传海报与杂志宣传动员
1942 年至 1945 年间发布的《生活》杂志以及战时海报，充分动员女性参加二战中的军队与劳动中。杂志和宣传海报等纸质媒介通过标志性形象的设计与传播、爱国口号等策略，充分动员女性填补男性劳动力的空缺。标志性形象的设计与传播方面，通过塑造“罗西·铆钉工”（Rosie the Riveter）（由J. Howard Miller设计的“We Can Do It!”海报，以蓝领工装、红头巾、卷袖露臂的坚定形象，成为女性力量的象征）形象，树立典范引导女性参加工作，在海报竞赛Artists for Victory（AFV）和全国战争宣传海报大赛（NWPC）中，大量强调“敌人破坏母亲形象”，通过将敌人塑造成破坏家庭与母性价值的暴徒，激起了美国民众特别是女性群体的共鸣，这种宣传方式不仅重塑了敌人形象，同时也在无形中强化了国内女性作为家庭守护者的社会地位【3】【4】；爱国口号方面，美国方面提出“更快赢得战争需要更多女性工作”的口号，德国方面提出“妇女帮助赢得胜利”的口号，强调女性的重要性，推动女性为国工作，为国战斗。
### 2.1.2 通过立法强制要求女性参与生产
美国于1941年《国家服务法案》强制征召18-50岁女性进入关键行业，如弹药生产（女性占比达36.8%）。1943年，18-20岁女性中42%从事金属与化学产业【5】。英国于1941年发布《国家服务法案（第二号）》，要求18-50岁未婚女性在军队、民防或工厂工作，与1943年强制女性进入金属制造、化工业等关键部门，违者罚款或监禁。
通过宣传与强制双管并行的方式，有效的利用女性劳动力推动国家生产力的提升。同时，女性通过劳动的付出交换到了更多的社会权利，推动女性从私人领域走向了公共领域,取得了部分经济独立。



## 2.2 宣传引起的对女性形象的重塑
爱国形象。政府急于弥补劳动力的短缺,因此非常重视争取妇  女 支 持 的 战 争 使 命。OWI提出了“家庭前线英雄” 的概念,发展成为女性的一种新的社 会身份。这种观念突出了妇女的责任感,宣扬了爱国主义思想,意在 激 发 妇女 进 入 就 业市场 的 欲 望。
强壮、健康的女性形象。政府通过操纵女性形象的审美来塑造  更强大的女性形象,使产业工作更符合女性的新模式,从而带动了  产业工作。政府有意在宣传海报上重建身材匀称、轮廓肌肉发达的女性形  象,让女性做好满足劳动力需求的准备。
独立的女性形象。为了鼓励美国妇女参战,美国政府机构做出了巨大努力,创造了一个女性独立和领导的海市蜃楼,在战争期间,  女性得到了前所未有的尊重。【6】

# 3.对战后女性地位的影响
## 3.1 战时就业的暂时性与长期效应
虽然二战期间女性大量进入职场，但根据Goldin的研究显示，战争结束后，对女性劳动力的需求减少，因社会习惯和家庭责任的安排，许多女性被鼓励，甚至被迫返回家庭角色。研究指出，只有大约20%的战时新入职女性在战后仍继续保持就业状态。这种现象反映出战争所带动的女性经济参与具有一定的暂时性，但同时也为后来的就业转型和女性自主经济能力的培育提供了基础。比如，战时政府（如兰汉姆法案）设立托儿所等支持政策，为女性未来就业设置了制度基础。此外，女性在战争中积累的工作经验和独立意识，成为推动战后性别平等和民权运动潜在动力。【7】
## 3.2为日后民权运动奠定基础
女性被安排在需要更高自主性和责任感的岗位上，她们承担了传统上由男性主导的工作，这促使她们获得了全新的自信与能力。战争时期的这些经历让女性更加渴望拥有平等权利和参与社会决策的机会，许多女性在战后成为追求民权和性别平等运动的积极参与者。她们在战时获得的经验、组织能力和公众认可，为战后女性争取平等工资、投票权和更广泛公民权利的运动提供了坚实基础。同时，尽管社会对女性在男性主导领域中工作的接受是暂时的，但这为改革者在后来的民权时代争取权益提供了重要的先例和论据。因此，二战成为女性民权运动的重要转折点和催化剂。【2】
